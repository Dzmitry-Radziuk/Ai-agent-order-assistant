# Обзор

Restaurant Procurement Bot принимает заказы сотрудников кафе в Telegram и проводит их от первого сообщения до подтверждённой записи в Google Sheets.

## Основные свойства

- FastAPI быстро и идемпотентно принимает Telegram update.
- Celery Worker выполняет долгую обработку вне webhook-запроса.
- PostgreSQL хранит долговечное состояние, контрольные точки и ограниченный аудит заказа.
- Redis используется только для временных данных: очереди, кэша и блокировок.
- Запись заказа защищена контрольными точками, чтобы повтор задачи не создавал дубликаты.

## Границы

Telegram, OpenAI, Google Sheets, Google Apps Script и Langfuse являются внешними системами. Их доступность и сохранность данных контролируются их владельцами.

## Эксплуатация

Приложение разворачивается через Docker Compose. Перед API и worker запускаются миграции базы данных. Health endpoints проверяют процесс приложения, PostgreSQL и Redis.
