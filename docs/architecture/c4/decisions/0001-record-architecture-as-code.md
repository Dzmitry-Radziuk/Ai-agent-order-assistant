# 1. Хранить C4-модель как код в основном репозитории

Дата: 2026-07-24

## Статус

Принято

## Контекст

Архитектурная схема должна соответствовать реальному коду и меняться вместе с ним. Отдельная ветка или ручная копия диаграммы в Wiki быстро расходятся с реализацией.

## Решение

Хранить исходную Structurizr DSL-модель, документацию, ADR и экспортированные Mermaid-диаграммы в `docs/architecture/c4`. В GitLab Wiki публиковать только обзор и ссылки на файлы основной ветки.

## Последствия

- Изменения архитектуры можно проверять в merge request вместе с кодом.
- Диаграммы воспроизводимо валидируются и экспортируются.
- При изменении контейнеров, интеграций или основного сценария заказа необходимо обновлять DSL и Mermaid-экспорт.
- Wiki не является источником истины и не должна содержать отдельную редактируемую копию модели.
