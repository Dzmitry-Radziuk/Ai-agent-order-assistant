# Документация проекта

В корне `docs/` находятся документы, описывающие текущее состояние проекта.
Завершённые аудиты, планы и диагностические снимки перенесены в
[`archive/README.md`](archive/README.md) и не являются источником текущего
архитектурного или эксплуатационного контракта.

## Актуальные документы

- [`CURRENT_ARCHITECTURE.md`](CURRENT_ARCHITECTURE.md) — фактические границы
  модулей и владельцы ответственности.
- [`TESTING_READINESS.md`](TESTING_READINESS.md) — подтверждённые проверки и
  готовность к тестированию.
- [`USER_SCENARIOS.md`](USER_SCENARIOS.md) — описание пользовательских
  сценариев, сгенерированное из канонического источника.
- [`CHANNEL_EXTENSION_GUIDE.md`](CHANNEL_EXTENSION_GUIDE.md) — правила
  добавления новых каналов.
- [`INDEPENDENT_ENGINEERING_AUDIT.md`](INDEPENDENT_ENGINEERING_AUDIT.md) —
  последний независимый аудит и список открытых вопросов.

## Специализированные разделы

- [`ci/README.md`](ci/README.md) — CI-контекст.
- [`user-scenarios/scenarios.json`](user-scenarios/scenarios.json) —
  канонический источник сценариев.
- [`user-scenarios/index.html`](user-scenarios/index.html) — сгенерированный
  HTML-каталог сценариев.
